# 💪 FitTrack

A simple fitness tracker that runs entirely in the browser. Log workouts, track a weekly minutes goal, and see your last 7 days in a chart. Data is saved in your browser's localStorage, so there is no backend or login.

## Features
- Log workouts (date, exercise, duration, calories)
- Weekly summary: total minutes, calories, workouts, and day streak
- Adjustable weekly goal with a progress bar
- 7-day bar chart (Chart.js)
- Delete entries
- Responsive layout with automatic dark mode

## Tech
HTML, CSS, JavaScript, [Chart.js](https://www.chartjs.org/)

## Run locally
1. Clone the repo: `git clone https://github.com/<your-username>/fittrack.git`
2. Open `index.html` in your browser
